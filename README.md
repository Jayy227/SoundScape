# SoundScape

Aplikasi majalah musik digital masa kini yang menggabungkan kedalaman jurnalistik, pengalaman audio interaktif, dan kecerdasan buatan (AI). Aplikasi ini dirancang khusus untuk para pecinta musik yang ingin menyelami kisah di balik lagu.

## Tech Stack

- React 19 + TypeScript + Vite 8
- Tailwind CSS v4
- ThreeUI `CharacterCarousel` (Wave variant — SHA-256 registered source)
- Lucide React icons + Canvas Confetti

## Fitur

- **Character Wave Carousel** — 3D dimensional card wave (ThreeUI)
- **In-App Mini Player** — audio playback dengan rekomendasi playlist
- **AI Secret Vault** — informasi artis di luar majalah (gear, studio, unreleased)
- **Rating & Ulasan** — bintang + komentar per artis
- **Simpan Favorit** — lokal-persist via localStorage
- **10 Artis** — Daniel Caesar, Rex Orange County, Mateus Asato, James Arthur, Keshi, d4vd, Bruno Mars, John Mayer, Alex Crichton, + lainnya

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview build
